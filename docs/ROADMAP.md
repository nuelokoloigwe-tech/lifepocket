# LifePocket Roadmap

## Build 001 — Core prototype
Dashboard, basic payment reminders, tasks, calendar and local persistence.

## Build 002 — Personal Life & Finance (current)
Complete the local prototype experience: recurring payment reminders, payment history, tasks, shopping list and document metadata index. Bank functionality is explicitly excluded.

## Build 003 — Personal finance planning
Manual income and expense ledger, categories, budgets, budget-vs-actual reporting, debt/loan planning and savings goals. Still no bank connections unless separately approved.

## Build 004 — Cloud & identity
Authentication, user-specific database, cloud sync, secure document storage, backup and recovery.

## Build 005 — Notifications & household
Scheduled reminders, household sharing, permissions, family tasks and shared commitments.

## Build 006 — LifePocket AI
Natural-language task creation, summaries and user-controlled insights.

## Build 007 — Commercial readiness
Subscription plans, onboarding, analytics, security review, accessibility and production deployment.
